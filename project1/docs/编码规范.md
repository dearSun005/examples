## 3. 命名约定

### 3.1 Python / Django（后端）

| 对象 | 约定 | 示例 |
| --- | --- | --- |
| 模块/文件 | snake_case | `todos/views.py` |
| 类 | PascalCase | `TodoListAPIView` |
| 函数/方法 | snake_case | `logical_delete_todo` |
| 变量 | snake_case | `author_id` |
| 常量 | UPPER_SNAKE_CASE | `MAX_PAGE_SIZE = 50` |
| Django Model | PascalCase 单数 | `Todo`、`GroupMember` |
| Model 字段 | snake_case | `is_deleted`、`created_at` |
| 数据库表名 | snake_case 复数（Django 默认） | `todos`、`group_members` |
| URL 路径 | kebab-case 或下划线，统一用连字符 | `/api/v1/todos/{id}/logical-delete` |
| 配置项 | UPPER_SNAKE_CASE（环境变量） | `JWT_SECRET_KEY` |

### 3.2 TypeScript / React（前端）

| 对象 | 约定 | 示例 |
| --- | --- | --- |
| 文件（组件） | PascalCase.tsx | `TodoList.tsx` |
| 文件（非组件） | camelCase.ts 或 kebab-case.ts | `request.ts`、`todo-api.ts` |
| 组件 | PascalCase | `TodoList`、`TodoItem` |
| 函数 | camelCase | `addTodo`、`fetchTodoList` |
| 变量 | camelCase | `todoList`、`isLoading` |
| 常量 | UPPER_SNAKE_CASE | `MAX_TODOS`、`ROLE_TYPES` |
| 类型/接口 | PascalCase | `Todo`、`TodoListProps` |
| 枚举 | PascalCase + PascalCase 成员 | `enum TodoStatus { Pending, Done }` |
| CSS 类名 | kebab-case（Tailwind 优先） | `todo-item`、`btn-primary` |
| Hook | camelCase + use 前缀 | `useTodoList`、`useAuth` |

### 3.3 数据库

- 表名：snake_case 复数（Django 默认）
- 字段名：snake_case
- 主键：统一 `id`，BIGINT 自增（Django `BigAutoField`）
- 外键字段：`<引用对象>_id`，如 `author_id`、`group_id`
- 时间字段：`created_at` / `updated_at` / `deleted_at` / `expires_at`
- 布尔字段：`is_` 前缀，如 `is_deleted`、`is_active`、`is_read`
- 索引名：`idx_<表>_<字段>`，如 `idx_todo_author_deleted`

```python
from django.db import models


class Todo(models.Model):
    """待办事项模型。"""

    id = models.BigAutoField(primary_key=True)
    author = models.ForeignKey(
        "users.User",
        on_delete=models.CASCADE,
        related_name="todos",
        db_column="author_id",

    description = models.CharField(max_length=500, blank=True, default="")
    due_at = models.DateTimeField(null=True, blank=True)
    priority = models.CharField(
        max_length=10, choices=Priority.choices, default=Priority.MEDIUM
    )
    status = models.CharField(
        max_length=10, choices=Status.choices, default=Status.PENDING
    )
    is_deleted = models.BooleanField(default=False)
    deleted_by = models.ForeignKey(
        "users.User",
        on_delete=models.SET_NULL,
        null=True,
        blank=True,
        related_name="deleted_todos",
        db_column="deleted_by",
    )
    deleted_at = models.DateTimeField(null=True, blank=True)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        db_table = "todos"
        indexes = [
            models.Index(fields=["author", "is_deleted", "-created_at"],
                         name="idx_todo_author_deleted"),
            models.Index(fields=["is_deleted", "created_at"],
```

### 4.4 数据访问层抽象（Manager / Repository）

- 复杂查询（权限引擎可见性判定、跨组聚合）通过自定义 Manager 封装
- Manager 方法返回 QuerySet，便于链式调用
- 切换 MySQL 时，隔离 ORM 专有语法在 Manager 内部

```python
from django.db import models
from django.db.models import QuerySet, Q


class TodoManager(models.Manager):
    """待办数据访问层，封装权限引擎可见性查询。"""

    def visible_for(self, user) -> "QuerySet[Todo]":
        """返回 user 可见的待办（权限引擎可见性判定，对齐 PRD 附录 A 6 步规则）。

        1. 作者本人全部待办（含被逻辑删除）
        2. 一级管理员：全部
        3. 组长：本组成员待办
        4. 二级管理员：管辖组成员待办
        """
        from apps.users.permissions import (
            is_platform_admin, is_group_leader_of,
            is_secondary_admin_of,
        )

        if is_platform_admin(user):
            return self.all()

        author_ids = list(self._member_author_ids_for(user))
        return self.filter(
            Q(author=user) | Q(author_id__in=author_ids, is_deleted=False)
        ).distinct()

    def _member_author_ids_for(self, user) -> set:
        """组长/二级管理员可见的成员 author_id 集合。"""
        from apps.users.permissions import (
            is_group_leader_of, is_secondary_admin_of,
        )

        ids = set()
        if is_group_leader_of(user):
            ids.update(user.led_groups_members().values_list("id", flat=True))
        if is_secondary_admin_of(user):
            ids.update(user.managed_groups_members().values_list("id", flat=True))
        return ids
```

### 4.5 权限引擎规范

- 权限判定**独立模块**，不散落在 View 中
- 可见性判定函数 `visibility(user, todo) -> bool`，严格按 PRD 附录 A 6 步规则
- 操作权限判定 `can_operate(user, todo, action) -> bool`
- 越权统一返回 403，**不泄露资源是否存在**（对不可见资源也返回 403，而非 404）

```python
from apps.users.models import User
from apps.todos.models import Todo


def visibility(user: User, todo: Todo) -> bool:
    """可见性判定（PRD 附录 A 6 步规则）。"""
    # 1. 作者始终可见自己待办（含被他人逻辑删除）
    if todo.author_id == user.id:
        return True
    # 2. 他人不可见被逻辑删除的待办
    if todo.is_deleted:
        return False
    # 3. 一级管理员可见全部
    if user.is_platform_admin:
        return True
    # 4. 组长可见本组成员待办
    if user.is_leader_of(todo.author):
        return True
    # 5. 二级管理员可见管辖组成员待办
    if user.is_secondary_admin_of(todo.author):
        return True
    # 6. 其他不可见
    return False


def can_operate(user: User, todo: Todo, action: str) -> bool:
    """操作权限判定（PRD 附录 A 操作矩阵）。"""
    if action in ("view", "logical_delete"):
        return visibility(user, todo)

    # 物理删除：仅作者本人
    if action == "physical_delete":
        return todo.author_id == user.id

    # 修改他人待办字段：一律禁止（含管理员/组长），仅作者本人可修改
    if action == "update":
        return todo.author_id == user.id

    # 恢复：仅 deleted_by == 作者本人 的可恢复
    if action == "restore":
        return (
            todo.is_deleted
            and todo.deleted_by_id == user.id
            and todo.author_id == user.id
        )

    return False
```

### 4.6 删除管理规范

- 逻辑删除：写 `is_deleted=True` + `deleted_by` + `deleted_at`
- 逻辑删除幂等：已 `is_deleted=True` 的再次删除，返回 200 + 当前状态，不报错、不重复写入
- 物理删除：仅原作者本人；需 `confirm=true` 二次确认
- 恢复：仅 `deleted_by == 作者本人` 可恢复；他人删除的返回 403

```python
from django.utils import timezone
from rest_framework import status
from rest_framework.response import Response
from apps.todos.models import Todo
from apps.todos.permissions import can_operate


class TodoDeleteService:
    """删除分级服务：统一处理逻辑删除/物理删除/幂等/恢复边界。"""

    @staticmethod
    def logical_delete(todo: Todo, operator) -> Response:
        # 幂等：已逻辑删除再次发起，返回 200 + 当前状态（PRD 附录 B.4）
        if todo.is_deleted:
            return Response(
                {"is_deleted": True, "deleted_by": todo.deleted_by_id,
                 "deleted_at": todo.deleted_at},
                status=status.HTTP_200_OK,
            )

        if not can_operate(operator, todo, "logical_delete"):
            return Response(
                {"code": "PERMISSION_DENIED",
                 "message": "无权访问",
                 "detail": "资源不可见或无操作权限"},
                status=status.HTTP_403_FORBIDDEN,
            )

        todo.is_deleted = True
        todo.deleted_by = operator
        todo.deleted_at = timezone.now()
        todo.save(update_fields=["is_deleted", "deleted_by", "deleted_at"])
        return Response({"is_deleted": True}, status=status.HTTP_200_OK)

    @staticmethod
    def physical_delete(todo: Todo, operator, confirm: bool) -> Response:
        if not can_operate(operator, todo, "physical_delete"):
            return Response(
                {"code": "PERMISSION_DENIED",
                 "message": "无权访问",
                 "detail": "资源不可见或无操作权限"},
                status=status.HTTP_403_FORBIDDEN,
            )
        if not confirm:
            return Response(
                {"code": "CONFIRM_REQUIRED",
                 "message": "需二次确认",
                 "detail": "物理删除不可恢复，请传 confirm=true"},
                status=status.HTTP_400_BAD_REQUEST,
            )
        todo.delete()
        return Response(status=status.HTTP_200_OK)

    @staticmethod
    def restore(todo: Todo, operator) -> Response:
        if not can_operate(operator, todo, "restore"):
            return Response(
                {"code": "PERMISSION_DENIED",
                 "message": "无权访问",
                 "detail": "仅可恢复自己逻辑删除的待办"},
                status=status.HTTP_403_FORBIDDEN,
            )
        todo.is_deleted = False
        todo.deleted_by = None
        todo.deleted_at = None
        todo.save(update_fields=["is_deleted", "deleted_by", "deleted_at"])
        return Response({"is_deleted": False}, status=status.HTTP_200_OK)
```

### 5.4 状态管理

- 优先使用 React 内置状态（useState/useReducer）+ Context
- 跨页面共享状态（如当前用户、JWT）用 Context 或 Zustand
- 不使用 Redux（项目规模不需要）

```typescript
// src/store/AuthContext.tsx
import { createContext, useContext, useState, ReactNode } from "react";

interface AuthState {
  user: User | null;
  accessToken: string | null;
  login: (token: string, user: User) => void;
  logout: () => void;
}

const AuthContext = createContext<AuthState | undefined>(undefined);

export function AuthProvider({ children }: { children: ReactNode }) {
  const [accessToken, setAccessToken] = useState<string | null>(
    localStorage.getItem("access_token")
  );
  const [user, setUser] = useState<User | null>(null);

  const login = (token: string, nextUser: User) => {
    localStorage.setItem("access_token", token);
    setAccessToken(token);
    setUser(nextUser);
  };

  const logout = () => {
    localStorage.removeItem("access_token");
    setAccessToken(null);
    setUser(null);
  };

  return (
    <AuthContext.Provider value={{ user, accessToken, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth(): AuthState {
  const ctx = useContext(AuthContext);
  if (!ctx) throw new Error("useAuth must be used within AuthProvider");
  return ctx;
}
```

### 5.5 路由规范

- 路由路径与后端 URL 对齐：`/todos`、`/todos/:id`、`/groups`、`/admin/todos`
- 受保护路由用 `<ProtectedRoute>` 包裹，校验角色

```typescript
// src/components/common/ProtectedRoute.tsx
import { ReactNode } from "react";
import { Navigate, useLocation } from "react-router-dom";
import { useAuth } from "@/store/AuthContext";
import type { UserRole } from "@/types/user";

interface ProtectedRouteProps {
  children: ReactNode;
  roles?: UserRole[]; // 允许访问的角色，不传表示任意登录用户
}

export function ProtectedRoute({ children, roles }: ProtectedRouteProps) {
  const { user, accessToken } = useAuth();
  const location = useLocation();

  if (!accessToken) {
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  if (roles && user && !roles.includes(user.role)) {
    return <Navigate to="/403" replace />;
  }

  return <>{children}</>;
}

// src/App.tsx 路由示例
import { Routes, Route } from "react-router-dom";
import { ProtectedRoute } from "@/components/common/ProtectedRoute";

export default function App() {
  return (
    <Routes>
      <Route path="/login" element={<LoginPage />} />
      <Route
        path="/todos"
        element={
          <ProtectedRoute>
            <TodoListPage />
          </ProtectedRoute>
        }
      />
      <Route
        path="/admin/todos"
        element={
          <ProtectedRoute roles={["platform_admin"]}>
            <AdminTodoListPage />
          </ProtectedRoute>
        }
      />
    </Routes>
  );
}
```

## 6. 数据库规范（MySQL 迁移兼容）

### 6.1 类型映射

| Django 字段 | sqlite3 存储 | MySQL 存储 | 备注 |
| --- | --- | --- | --- |
| BigAutoField | INTEGER | BIGINT AUTO_INCREMENT | 主键统一 BIGINT |
| CharField | TEXT/VARCHAR | VARCHAR | 显式 max_length |
| DateTimeField | TEXT | DATETIME | UTC 存储 |
| BooleanField | INTEGER 0/1 | TINYINT(1) | |
| ForeignKey | INTEGER | BIGINT | 显式外键约束 |

### 6.2 硬约束

- **禁用 sqlite 专有类型与语义**（如 AUTOINCREMENT 特殊行为）
- **外键显式声明**，sqlite 启用 `PRAGMA foreign_keys=ON`
- **主键统一 BIGINT 自增**（`BigAutoField`）
- **时间字段统一 UTC 存储**，对外输出 ISO8601 字符串
- **不依赖 sqlite 隐式类型转换**
- **数据访问层抽象为 Manager/Repository**，隔离 ORM 专有语法

### 6.3 索引策略

- 高频过滤字段建索引：`author_id`、`is_deleted`、`group_id`、`user_id`
- 复合索引按最左前缀：`idx_todo_author_deleted (author_id, is_deleted, created_at DESC)`
- M:N 中间表对 `(group_id, user_id)` 建 UNIQUE 约束

### 6.4 迁移

- 每次模型变更必须 `python manage.py makemigrations` 生成迁移
- 迁移文件提交到版本库，不手动修改
- 生产部署前 `python manage.py migrate --plan` 预览

## 7. 接口规范

### 7.1 REST 路由

- 统一前缀 `/api/v1`
- 资源用复数：`/todos`、`/groups`
- 子动作用连字符：`/todos/{id}/logical-delete`、`/todos/{id}/physical-delete`、`/todos/{id}/toggle-done`

### 7.2 统一响应格式

成功：
```json
{
  "code": "OK",
  "data": { ... }
}
```

失败：
```json
{
  "code": "PERMISSION_DENIED",
  "message": "无权访问",
  "detail": "资源不可见或无操作权限"
}
```

### 7.3 HTTP 状态码

| 场景 | 状态码 |
| --- | --- |
| 成功（GET/POST） | 200 / 201 |
| 创建/更新成功 | 200 |
| 资源不存在（本人可见） | 404 |
| 越权（不可见或无操作权限） | **403**（不泄露资源是否存在） |
| 未登录 / Token 失效 | 401 |
| 参数错误 | 400 |
| 冲突（重复邮箱、已在组） | 409 |

### 7.4 分页

- 入参：`page`（默认 1）、`page_size`（默认 20，最大 50）
- 出参：
```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

### 7.5 JWT 鉴权

- Header：`Authorization: Bearer <access_token>`
- Access Token 有效期 ≤ 2h
- Refresh Token 有效期 ≤ 7d
- 全站统一 JWT，不引入 Cookie/CSRF

## 8. 安全规范

- 密码加盐哈希存储（bcrypt/argon2），**禁止明文**
- 连续 5 次登录失败锁定账号 5 分钟（F18）
- 越权访问统一返回 403，**响应体不泄露资源是否存在**
- 二次确认操作：物理删除、组解散
- 配置项（DB 连接、JWT 密钥、邀请码有效期）通过环境变量注入，**不硬编码**
- CORS 仅允许前端域名
- SQL 注入防护：使用 ORM，禁止拼接原生 SQL

## 10. 测试规范

### 10.1 后端测试

- 单元测试：权限引擎、删除管理、幂等逻辑（Django TestCase）
- 接口测试：F01-F16 全功能点，覆盖异常分支（400/401/403/409）
- 越权测试：附录 B 全场景 100% 拦截（独立用例集）
- 覆盖率：权限引擎与删除管理 ≥ 80%
- 测试文件位置：`backend/tests/` 或各 app 的 `tests.py`

```python
from django.test import TestCase
from apps.users.models import User
from apps.todos.models import Todo
from apps.todos.permissions import visibility, can_operate


class PermissionEngineTest(TestCase):
    """权限引擎可见性判定测试（对齐 PRD 附录 A 6 步规则）。"""

    def setUp(self):
        self.author = User.objects.create_user(
            email="author@example.com", password="pass1234"
        )
        self.other = User.objects.create_user(
            email="other@example.com", password="pass1234"
        )
        self.todo = Todo.objects.create(
            author=self.author, title="测试待办"
        )

    def test_author_can_see_own_todo(self):
        """作者始终可见自己待办。"""
        self.assertTrue(visibility(self.author, self.todo))

    def test_other_cannot_see_others_todo_without_group(self):
        """无组关系的其他用户不可见他人待办。"""
        self.assertFalse(visibility(self.other, self.todo))

    def test_author_can_see_own_deleted_todo(self):
        """作者始终可见自己待办（含被他人逻辑删除）。"""
        self.todo.is_deleted = True
        self.todo.deleted_by = self.other
        self.todo.save()
        self.assertTrue(visibility(self.author, self.todo))

    def test_other_cannot_see_logically_deleted_todo(self):
        """他人不可见被逻辑删除的待办。"""
        self.todo.is_deleted = True
        self.todo.deleted_by = self.author
        self.todo.save()
        self.assertFalse(visibility(self.other, self.todo))

    def test_only_author_can_physical_delete(self):
        """物理删除仅限作者本人。"""
        self.assertTrue(
            can_operate(self.author, self.todo, "physical_delete")
        )
        self.assertFalse(
            can_operate(self.other, self.todo, "physical_delete")
        )

    def test_only_author_can_restore_own_deleted(self):
        """恢复仅限 deleted_by == 作者本人。"""
        self.todo.is_deleted = True
        self.todo.deleted_by = self.author
        self.todo.save()
        self.assertTrue(can_operate(self.author, self.todo, "restore"))

        self.todo.deleted_by = self.other
        self.todo.save()
        self.assertFalse(can_operate(self.author, self.todo, "restore"))
```

## 12. 反例与禁用项

### 12.1 后端禁用

| ❌ 禁止 | ✅ 正确做法 |
| --- | --- |
| `objects.filter().filter()` 散落权限判定 | 通过 `TodoManager.visible_for(user)` 统一判定（见 4.4） |
| View 直接操作 `is_deleted` | 走 `TodoDeleteService` 删除管理服务（见 4.6） |
| 返回 404 来"隐藏"越权 | 统一返回 403，不泄露资源是否存在（见 4.5） |
| 循环中查 N+1 查询 | 用 `select_related`（外键）/ `prefetch_related`（M:N）预加载 |
| 硬编码配置项（DB / JWT / 邀请码有效期） | 通过 `os.environ` + Django settings 注入 |

### 12.2 前端禁用

| ❌ 禁止 | ✅ 正确做法 |
| --- | --- |
| 使用 `any` | 用 `unknown` + 类型守卫，或显式定义 interface |
| class 组件 | 统一函数组件 + Hooks（见 5.1） |
| 组件内直接调 `axios` | 通过 `src/api/` 封装的函数调用（见 5.3） |
| 组件内处理 JWT | 走 Axios 拦截器统一注入与刷新（见 5.3） |
| 内联样式 `style={{...}}` | 用 Tailwind 类名，如 `className="space-y-2"` |
